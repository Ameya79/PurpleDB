# Git Remote Sync Invariant

- Remote URL: `https://github.com/Ameya79/PurpleDB.git`
- Keep remote `origin` configured to this repository.
- After every few atomic commits on a milestone branch (e.g. `m1-cpp-foundations`), push changes to `origin`.
- Never leave finished milestone work only in the local working copy.
